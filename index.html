Administrar iniciativas

Las 9 iniciativas oficiales vienen precargadas. Puede editar código, nombre, resumen, área, responsable y estado; los cambios se guardan en este navegador mediante localStorage.

QR de votación

Publique este HTML en una URL accesible y comparta el QR con el Comité. En local, el QR abrirá esta misma ruta si el dispositivo la puede alcanzar.

Para uso real multiusuario, conecte Firebase o Supabase en la sección Producción. Sin base compartida, cada navegador conservará sus propios votos.

Importar iniciativas desde JSON

Pegue un arreglo JSON con campos: code, name, description, area, owner, state.

Preparación para producción multiusuario

La herramienta funciona en modo demo local. Para una sesión real del Comité con celulares, publique el archivo y active un almacenamiento compartido.

Limitación del HTML estático: localStorage no sincroniza votos entre dispositivos. Cada navegador guarda su propia copia.

Opción A: Firebase Firestore

  1. Crear proyecto en Firebase.
  2. Activar Firestore Database.
  3. Crear colecciones: initiatives y votes.
  4. Insertar configuración en el bloque PRODUCTION_CONFIG del código.
  5. Implementar reglas de seguridad según correo, dominio o token del comité.
  6. Cambiar STORAGE_MODE de local a firebase y completar funciones marcadas como TODO.

Opción B: Supabase

  1. Crear proyecto en Supabase.
  2. Crear tablas: initiatives y votes.
  3. Insertar URL y anon key en PRODUCTION_CONFIG.
  4. Definir Row Level Security para permitir voto controlado y lectura consolidada.
  5. Cambiar STORAGE_MODE de local a supabase y completar funciones marcadas como TODO.

Modelo mínimo de datos sugerido

initiatives: { id, code, name, description, area, owner, state, createdAt, updatedAt }
votes: { id, initiativeId, voterRole, voterSessionId, scores: { I1...I8, E1...E4 }, createdAt, voterHash }

Para evitar duplicados, use un campo voterHash construido con correo institucional, rol o token único por evaluador. Si se desea anonimato, el hash debe generarse sin guardar el dato original.
